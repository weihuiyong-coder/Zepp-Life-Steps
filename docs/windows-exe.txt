Zepp 步数助手 · Windows EXE 版

适用：Windows 10 / 11，64 位（x64）。
无需另外安装 Node.js、Python，也不需要管理员权限。

使用方法
1. 如果收到的是 ZIP，先解压，再双击“Zepp步数助手.exe”。
2. 首次打开会准备内置运行环境，请稍等。完成后会自动打开原来的网页。
3. 输入自己的 Zepp Life 账号、密码和步数，点击“更新步数”。
4. 使用期间保留“Zepp 步数助手”窗口。关闭这个窗口会停止本机服务。

网页关闭后，可点击启动窗口里的“打开网页”重新进入。
下次使用时再次双击 EXE 即可，运行环境会复用。
默认使用 3107 端口；端口被占用时会自动选择其他空闲端口，请以启动窗口显示的地址为准。
每位同事在自己的电脑上运行 EXE，不需要访问他人电脑的地址。

提交结果
该版本保留原仓库网页，使用 miloce 仓库的登录接口，再提交指定步数。
只有步数接口返回成功码才会显示成功。微信/支付宝同步情况请在对应应用确认。
若提示请求过于频繁，请按页面倒计时等待后再手动提交。

文件与环境
这是内置运行环境的单文件应用，首次运行会自动解压到：
%LOCALAPPDATA%\ZeppLifeSteps
解压后运行文件约占 151 MB。运行步数功能仍需要互联网连接。
账号密码不写入文件或日志，登录令牌仅在运行时内存中暂存。
浏览器历史记录由本机浏览器保存；交付包不包含测试者的账号、密码、令牌或历史。
程序为本次本地构建版本，未进行代码签名。
